Shared files & reservations

COORD agents reserve files and publish changes only if their starting version still matches. Conflicting changes are refused.

How edits stay safe

COORD controls changes published through its tools. Other editors can still change local files; those edits never silently overwrite a teammate’s newer version. Service-backed projects require the service online; temporary projects require the host computer online. COORD sees activity reported through its tools; it does not inspect an agent’s internal subagents or private conversations.

Source files only: up to 500 text files, 1 MiB each and 16 MiB total. Recognized secrets, binary files, and build folders are excluded.

No Git push or pull. An internet connection and a reachable project host are required.
